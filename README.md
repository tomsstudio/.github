# .github

Tom's Studio's organisation profile. [profile/README.md](profile/README.md) is what renders at
[github.com/tomsstudio](https://github.com/tomsstudio).

The activity graph (`profile/assets/commits-*.svg`) is pushed here daily by the workflow in
[tomsstudio/.github-private](https://github.com/tomsstudio/.github-private) — this repo has no
refresh job of its own, so those two files will look untouched by any commit made here.
